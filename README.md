This repository contains basic Python programs created for learning and practice.

## Programs Included

- ATM System
- Shopping Cart
- Marksheet
- Simple Calculator
- Car Game
- Stone Paper Scissor Game

Python

This repository is created to practice Python programming concepts such as:

- Conditional statements
- Loops
- Functions
- Lists and dictionaries
- Object-Oriented Programming
- Basic game logic
